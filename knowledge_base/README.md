# AcmeFlow SaaS 产品知识库

这是项目演示使用的虚拟企业 SaaS 产品资料。将本目录中的 Markdown 文件上传到 Dify 知识库后，可以直接测试账号、权限、项目、API、套餐和故障排查问题。

## 文档清单

- `01-account.md`：账号与登录
- `02-members-permissions.md`：成员与权限
- `03-projects-and-import.md`：项目和数据导入
- `04-api.md`：API 与 Webhook
- `05-billing.md`：套餐、发票和退款
- `06-troubleshooting.md`：常见故障排查

## 统一产品背景

AcmeFlow 是面向中小团队的项目协作 SaaS。用户可以创建项目、导入客户数据、通过 API 查询任务，并邀请团队成员共同协作。
