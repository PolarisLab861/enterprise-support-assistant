# AcmeFlow 常见故障排查

## 页面加载缓慢

先确认网络连接和浏览器版本，再尝试无痕窗口访问。如果只有单个项目加载缓慢，请提供项目 ID 和浏览器控制台错误，由技术支持进一步排查。

## API 返回 401

确认 Authorization 格式为 `Bearer <api-key>`，检查 Key 是否被撤销，以及请求是否发送到了正确的工作区地址。不要在工单中粘贴完整 API Key，只提供前 4 位和后 4 位。

## API 返回 429

这是调用频率超限。请读取 `Retry-After` 并等待后重试，或降低并发。重复立即重试不会解除限制。

## 数据导入后数量不一致

先检查导入报告中的失败行和重复客户 ID，再确认是否使用了正确的工作区和项目。请保留导入批次编号，方便客服定位。
