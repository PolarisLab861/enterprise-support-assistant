# AcmeFlow 套餐、发票与退款

## 套餐

- 基础版：最多 5 名成员，基础项目功能和每分钟 60 次 API 调用。
- 专业版：最多 50 名成员，报表导出、审计日志和每分钟 600 次 API 调用。
- 企业版：成员数和 API 限额可定制，支持专属客服和私有部署评估。

## 升级套餐

Owner 可以进入“工作区设置 > 账单”升级套餐。升级会立即生效，费用按当前账期剩余天数折算。

## 发票

付款成功后，在“账单 > 发票”中下载电子发票。发票抬头或税号填写错误时，不要重复提交付款，应提交人工工单申请重新开票。

## 退款

退款申请必须由 Owner 提交。客服只能记录申请并转人工审核，不能直接承诺退款金额或处理时限。涉及退款的问题必须创建高优先级工单。
