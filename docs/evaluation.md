# 评测方案与测试问题

## 1. 评测目标

验证系统是否能做到：

- 正确识别问题类型。
- 找到支持答案的知识库内容。
- 不把知识库外信息编造成事实。
- 在高风险或低置信度场景下转人工。
- 返回可追溯的引用来源。

## 3. 指标定义

| 指标 | 定义 |
|---|---|
| 意图分类准确率 | 预测意图与标注意图一致的比例 |
| 检索命中率 | Top-K 中包含期望文档的比例 |
| 答案准确率 | 答案事实和解决步骤正确的比例 |
| 引用正确率 | 引用内容确实支持答案的比例 |
| 拒答准确率 | 知识库外问题被正确拒答的比例 |
| 转人工准确率 | 高风险问题被正确拦截的比例 |
| 平均响应时间 | 从 API 接收到返回结果的平均耗时 |
| 单次 Token 消耗 | 每次工作流运行消耗的输入和输出 Token |

## 6. 评测执行建议

1. 固定模型、温度、Top-K 和测试集版本。
2. 先运行 V1，保存每条问题的检索结果和答案。
3. 只修改一个变量，再运行 V2 或 V3。
4. 对失败案例进行人工标注，避免只看平均分。
5. 将每个修复后的失败案例加入回归集。
